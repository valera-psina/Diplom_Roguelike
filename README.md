# Diplom_Roguelike 🎲

Добро пожаловать в репозиторий проекта **Diplom_Roguelike** — моей дипломной работы в жанре рогалик. Здесь лежит весь исходный код, сцены, модели и текстуры проекта.

---

## 📋 Требования перед запуском

Чтобы проект корректно открылся и работал, убедись, что у тебя установлено следующее ПО:

- **Unity Hub** и **Unity Editor** версии **6000.3.22f1 LTS** (или новее LTS-версия).
- **Git** (система контроля версий).
- **Git LFS** (обязательно! Без него большие текстуры и модели не скачаются).

---

## 🚀 Как скачать и открыть проект

Проект использует **Git LFS** для хранения тяжёлых файлов (текстур, моделей, звуков). Поэтому важно выполнить все шаги по порядку.

### 1. Клонируй репозиторий

Открой командную строку (терминал) и выполни:

```bash
git clone https://github.com/valera-psina/Diplom_Roguelike.git
```

### 2. Перейди в папку проекта

```bash
cd Diplom_Roguelike
```

### 3. Скачай все LFS-файлы (обязательно!)

```bash
git lfs pull
```

Эта команда скачает все текстуры, модели и звуки (около 1.7 ГБ). Без этого шага в игре всё будет **белым** (пустые материалы).

### 4. Открой проект в Unity

- Запусти **Unity Hub**.
- Нажми **"Open"** и выбери папку `Diplom_Roguelike`, которую ты клонировал.
- Unity импортирует все ассеты и пакеты. Первый запуск может занять 5–10 минут — это нормально.

---

## 🔧 Управление проектом (для разработчиков)

Если ты планируешь не только играть, но и дорабатывать проект, используй **GitHub Desktop** или консоль для коммитов и пушей.

### Как добавить изменения:

1. Открой проект в Unity и внеси правки.
2. В GitHub Desktop выбери изменённые файлы, напиши понятное сообщение коммита.
3. Нажми **Commit to main**, затем **Push origin**.

**Важно:** Все большие файлы (`.png`, `.psd`, `.fbx`, `.wav` и др.) автоматически уходят в Git LFS благодаря настройкам в `.gitattributes`. Ничего дополнительно делать не нужно.

## 📁 Структура проекта (основные папки)

- `Assets/` — все игровые ресурсы: скрипты, сцены, модели, текстуры, звуки.
- `Packages/` — список используемых Unity-пакетов.
- `ProjectSettings/` — настройки проекта (графика, физика, управление, платформы).
